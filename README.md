# Viktor Fiedler – osobní digitální portfolio

Statický responzivní web pro doménu `viktorfiedler.cz`.

## Nasazení na Vercel
1. Nahrajte obsah této složky do kořene repozitáře `Fydlajz/viktorfiedler-web`.
2. Ve Vercelu vyberte **Add New → Project → Import Git Repository**.
3. Framework Preset: **Other**; Build Command nechte prázdný; Output Directory nechte výchozí.
4. Po úspěšném nasazení ověřte testovací adresu `*.vercel.app`.
5. Až potom připojte `viktorfiedler.cz` v Project → Settings → Domains a nastavte DNS přesně podle Vercelu.

## Soubory
- `index.html` – obsah stránky
- `styles.css` – design a mobilní zobrazení
- `script.js` – mobilní navigace a aktuální rok
- `assets/virtok.png` – autorský podpis používaný jen jako logo
- `assets/viktor-transparent.png` – schválená fotografie s průhledným pozadím

**Rozvržení:** text vlevo, fotografie vpravo. VIRTOK se objevuje pouze jako grafické logo v záhlaví.
